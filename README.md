# IIoT Decentralized Identity Framework (single zone: 1 fog node, N simulated devices)

## Setup
Python 3.11+. Run all commands from the directory that **contains** the `iiot/` folder.
```
python -m venv .venv && source .venv/bin/activate    # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Folder structure
```
iiot/
  common/   crypto.py models.py state.py log.py tls.py
  device/   device.py            (SimDevice, make_fleet, onboard_fleet)
  merkle/   tree.py registry.py  (Merkle tree, hash-chained root registry)
  fog/      serve.py app.py onboarding.py policy.py tokens.py revocation.py access.py
  attacks/  attack scenarios
  demo/     run_demo.py
  perf/     bench.py individual_vs_batch.py plots.py run_all_perf.py
  results/  generated CSVs, PNGs, environment.txt
tests/      test_<area>.py  (pytest.ini sets pythonpath=.)
docs/       notes from the foundation chat
```

## Commands
```
# Fog node with TLS (self-signed cert generated by common/tls.py); add --no-tls to disable
python -m iiot.fog.serve --port 8443 --psk demo-psk --admin-key demo-admin

# Demo (in-process); --tls starts a real TLS server subprocess; --pause waits for Enter between steps
python -m iiot.demo.run_demo [--tls] [--pause]

# Attacks (all five scenarios; table + non-zero exit code if any is not blocked)
python -m iiot.attacks.run_all

# Tests
python -m pytest tests -q

# Performance (bench + batch-vs-individual + plots + environment.txt)
python -m iiot.perf.run_all_perf [--counts 5 10 25 50 100] [--runs 5]
python -m iiot.perf.bench --counts 5 10 --runs 2        # individual steps
python -m iiot.perf.individual_vs_batch
python -m iiot.perf.plots                               # also prints markdown tables
```
Set `IIOT_NOCOLOR=1` to disable colored logs (perf scripts set it automatically).

## Result files (`iiot/results/`)
`raw_measurements.csv`: one row per sample.
| column | meaning |
|---|---|
| n_devices | fleet size N |
| run | run index (0-based) |
| metric | metric name (see below) |
| sample_idx | device index within the run; empty for once-per-run metrics |
| value | measured value |
| unit | `ms` or `per_s` |

`summary.csv`: per-run mean (and p95) of each metric, then averaged over runs.
| column | meaning |
|---|---|
| n_devices, metric, unit | as above |
| runs | number of runs |
| mean, std | mean and std dev (across runs) of the per-run mean |
| p95_mean, p95_std | mean and std dev (across runs) of the per-run 95th percentile |

Metrics: `registration_ms` (auth + key + PoP per device), `batch_close_ms` (POST /admin/batch/close), `batch_compute_ms` (sort + build_tree + root, no HTTP), `proof_all_ms` (all_proofs()), `proof_http_ms` (GET /proof/{did}), `verify_local_ms` (local verify_proof), `access_proof_allow_ms` / `access_proof_deny_ms` (end-to-end proof-mode /resource/access), `token_issue_ms` (POST /token/temp), `access_token_allow_ms` (temp-token validation, ALLOW path; sensor roles only) / `access_token_deny_ms`, `throughput_registrations_per_s`, `throughput_verifications_per_s` (proof-mode ALLOW over the whole fleet).

`batch_vs_individual.csv`:
| column | meaning |
|---|---|
| n_devices, mode, runs | N, `individual` or `batch`, runs |
| total_ms_mean, total_ms_std | total time to maintain root + issue proofs |
| root_updates | number of tree rebuilds/anchors performed |
| registry_blocks | blocks in the registry afterwards |
| stale_proofs_final | proofs that fail against the newest root |
| stale_proof_events | cumulative proof invalidations across all updates |
| amortized_ms_per_device_mean/std | total / N |

Plots: `graph1_devices_vs_batch_time.png`, `graph2_devices_vs_verification_latency.png`, `graph3_devices_vs_throughput.png`, `graph4_batch_vs_individual.png`. `environment.txt` records CPU, cores, OS, Python and package versions.

## Phases to files
Phase 1 (crypto, DIDs, models, state, device simulator): `common/`, `device/`. Phase 2 (Merkle tree, trusted root registry, logging/TLS, fog server): `merkle/`, `common/log.py`, `common/tls.py`, `fog/serve.py`. Phase 3 (PSK auth, key registration with proof of possession, batch epochs, proofs): `fog/app.py`, `fog/onboarding.py`. Phase 4 (temp tokens, policy, revocation, resource access): `fog/policy.py`, `fog/tokens.py`, `fog/revocation.py`, `fog/access.py`. Phase 5 (attacks and end-to-end demo): `attacks/`, `demo/run_demo.py`. Phase 6 (benchmarks, batch-vs-individual experiment, plots, docs): `perf/`, `results/`, `README.md`, `requirements.txt`.
